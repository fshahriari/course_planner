# 📚 انتخاب واحد (Course Planner)

یک اپلیکیشن تحت وب زیبا، سریع و مینیمال برای مدیریت و برنامه‌ریزی انتخاب واحد دانشجویان. این برنامه به صورت کاملاً Client-side (سمت کاربر) نوشته شده و اطلاعات شما را به صورت امن در مرورگر (Local Storage) ذخیره می‌کند.

![Course Planner Screenshot](https://raw.githubusercontent.com/fshahriari/course_planner/main/preview.png)

## ✨ ویژگی‌ها

- 🎨 **طراحی مدرن و پریمیوم:** رابط کاربری شیشه‌ای (Glassmorphism)، تایپوگرافی استاندارد (فونت وزیرمتن) و انیمیشن‌های روان.
- 🌓 **پشتیبانی از Dark/Light Mode:** قابلیت تغییر تم با انیمیشن زیبای View Transitions.
- 📅 **تقویم شمسی:** انتخاب تاریخ امتحانات با تقویم کاملاً شمسی و بومی.
- 🕒 **مدیریت کلاس‌ها:** وارد کردن ساعت و روزهای کلاس‌ها با پشتیبانی از روزهای چندگانه.
- 🧪 **مدیریت TA و آزمایشگاه:** امکان افزودن تایم‌های حل تمرین (TA) و آزمایشگاه به صورت زیرمجموعه یک درس، بدون تداخل با تاریخ امتحان اصلی.
- ⚔️ **تشخیص تداخل:** اخطار هوشمند در صورت تداخل روز و ساعت کلاس‌ها یا تاریخ امتحانات.
- 📁 **پلن‌های چندگانه:** امکان ایجاد بی‌نهایت برنامه (مثل پلن الف، پلن ب) برای مقایسه بهترین حالت انتخاب واحد.
- 📱 **واکنش‌گرا (Responsive):** سازگاری کامل با موبایل، تبلت و دسکتاپ.
- 📄 **خروجی PDF:** امکان پرینت و ذخیره برنامه به صورت PDF.

## 🚀 نحوه استفاده

این پروژه کاملاً استاتیک است و نیازی به نصب یا سرور خاصی ندارد. شما می‌توانید مستقیماً فایل `index.html` را در مرورگر باز کنید، یا آن را روی هاست استاتیک مثل **GitHub Pages** قرار دهید.

### اجرا روی GitHub Pages
این پروژه ۱۰۰٪ آماده‌ی قرارگیری روی گیت‌هاب پیجز است. فقط کافیست:
۱. در مخزن گیت‌هاب خود به بخش **Settings** بروید.
۲. وارد بخش **Pages** شوید.
۳. در قسمت *Source*، شاخه‌ی `main` را انتخاب و ذخیره کنید.
۴. پروژه شما در چند دقیقه به صورت زنده در دسترس خواهد بود!

## 🛠️ تکنولوژی‌های استفاده شده

- **HTML5 & Vanilla CSS:** بدون استفاده از هیچ فریم‌ورک سنگینی (No Tailwind, No Bootstrap)
- **Vanilla JavaScript:** کاملاً سبک، بدون React یا Vue
- **Jalaali-JS:** برای محاسبات تقویم جلالی
